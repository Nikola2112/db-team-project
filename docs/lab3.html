📃Сценарії використання

ID CreateUser
НАЗВА Створення користувача
УЧАСНИКИ Система, користувач
ПЕРЕДУМОВИ Користувач не зареєстрований системою
ОСНОВНИЙ СЦЕНАРІЙ

1. Користувач натискає кнопку "Зареєструватись".

2. Заповнення полей реєстрації користувачем (ім'я користувача, пароль, пошта).

3. Користувач натискає на кнопку "Створити".

4. Перевірка системою введених полей на валідність.

5. Створення системою облікового запису користувача.

6. Автоматичний вхід у систему користувача.
РЕЗУЛЬТАТ Створення облікового запису користувача
ВИКЛЮЧНІ СИТУАЦІЇ

- Користувач не ввів ім'я користувача (NullUsernameException)

- Користувач не ввів пароль (NullPasswordException)

- Користувач не ввів пошту (NullEmailException)

- Користувач з таким ім'ям вже існує (UserAlreadyExistsException)

- Користувач ввів недостатньо сильний пароль (WeakPasswordException)

- Користувач вказав неправильний формат пошти (WrongEmailFormatException)
ID UserAuthorization
НАЗВА Авторизація користувача
УЧАСНИКИ Система, користувач
ПЕРЕДУМОВИ Реєстрування користувача системою
ОСНОВНИЙ СЦЕНАРІЙ

1. Введення користувачем ім'я користувача та паролю.

2. Перевірка введених даних системою ( InvalidUsernameException або InvalidPasswordException).

3. Перевірка статусу користувача системою (UserBannedException).

4. Вхід користувача у систему.
РЕЗУЛЬТАТ Авторизація користувача системою
ВИКЛЮЧНІ СИТУАЦІЇ

- Введення неправильного паролю користувачем (InvalidPasswordException)

- Введення неправильного ім'я користувача користувачем (InvalidUsernameException)

- Заблокування системою користувача (UserBannedException)
