ID CreateUser
НАЗВА Створення користувача
УЧАСНИКИ Система, користувач
ПЕРЕДУМОВИ Користувач не зареєстрований системою
ОСНОВНИЙ СЦЕНАРІЙ

1. Користувач натискає кнопку "Зареєструватись".

2. Заповнення полей реєстрації користувачем (ім'я користувача, пароль, пошта).

3. Користувач натискає на кнопку "Створити".

4. Перевірка системою введених полей на валідність.

5. Створення системою облікового запису користувача.

6. Автоматичний вхід у систему користувача.
РЕЗУЛЬТАТ Створення облікового запису користувача
ВИКЛЮЧНІ СИТУАЦІЇ

- Користувач не ввів ім'я користувача (NullUsernameException)

- Користувач не ввів пароль (NullPasswordException)

- Користувач не ввів пошту (NullEmailException)

- Користувач з таким ім'ям вже існує (UserAlreadyExistsException)

- Користувач ввів недостатньо сильний пароль (WeakPasswordException)

- Користувач вказав неправильний формат пошти (WrongEmailFormatException)


ID UserAuthorization
НАЗВА Авторизація користувача
УЧАСНИКИ Система, користувач
ПЕРЕДУМОВИ Реєстрування користувача системою
ОСНОВНИЙ СЦЕНАРІЙ

1. Введення користувачем ім'я користувача та паролю.

2. Перевірка введених даних системою ( InvalidUsernameException або InvalidPasswordException).

3. Перевірка статусу користувача системою (UserBannedException).

4. Вхід користувача у систему.
РЕЗУЛЬТАТ Авторизація користувача системою
ВИКЛЮЧНІ СИТУАЦІЇ

- Введення неправильного паролю користувачем (InvalidPasswordException)

- Введення неправильного ім'я користувача користувачем (InvalidUsernameException)

- Заблокування системою користувача (UserBannedException)


ID EditUser
НАЗВА Редагування користувача
УЧАСНИКИ Адміністратор, користувач, система
ПЕРЕДУМОВИ Авторизування системою користувача або адміністратора
ОСНОВНИЙ СЦЕНАРІЙ

1. Адміністратор або користувач відкриває профіль користувача.

2. Користувач або адміністратор змінює потрібні поля.

3. Перевіркка прав системою (InsufficientPermissionsException).

4. Перевірка системою введених даних на валідність (InvalidDataFormatException).

5. Збереження системою оновлених даних користувача.
РЕЗУЛЬТАТ Змінення системою даних користувача
ВИКЛЮЧНІ СИТУАЦІЇ

- Користувач ввів дані у неправильному форматі (InvalidDataFormatException)

- Система не знайшла користувача (UserNotFoundException)

- Користувач має недостатньо прав для редагування (InsufficientPermissionsException)

ID RemoveUserFromProject
НАЗВА Видалення користувача з проєкту
УЧАСНИКИ Система, менеджер
ПЕРЕДУМОВИ Користувач є учасником проєкту
ОСНОВНИЙ СЦЕНАРІЙ

1. Менеджер переходить у розділ "Проєкти".

2. Менеджер обирає проєкт і натискає кнопку "Видалити користувача".

3. Відкриття системою форми для введення імені користувача

4. Введення менеджером імені користувача (можлива RemoveUserFromProject_WrongUsername_EXC).

5. Менеджер натискає кнопку "Видалити" (можлива RemoveUserFromProject_CancelButton_EXC).

6. Видалення системою користувача з проєкту.

7. Закриття системою форми.

8. Вивід системою повідомлення про успішне видалення користувача з проєкту.
РЕЗУЛЬТАТ Видалення учасника проєкту
ВИКЛЮЧНІ СИТУАЦІЇ

- RemoveUserFromProject_CancelButton_EXC – менеджер натиснув кнопку "Відміна"

- RemoveUserFromProject_WrongUsername_EXC – менеджер ввів неправильне ім'я користувача

ID BlockProject
НАЗВА Блокування проєкту
УЧАСНИКИ Система, адміністратор
ПЕРЕДУМОВИ

- Адміністратор вже є авторизованим

- Система містить дані про проєкт

- Проєкт порушує умови використання системи
ОСНОВНИЙ СЦЕНАРІЙ

1. Адміністратор переходить у розділ "Проєкти" та вибирає потрібний для блокування проєкт.

2. Адміністратор натискає кнопку "Заблокувати проєкт".

3. Система відкриває форму із параметрами блокування проєкту.

4. Адміністратор заповнює форму, вказуючи причину та термін дії блокування.

5. Адміністратор натискає кнопку "Підтвердити" (можлива BlockProject_CancelButton_EXC).

6. Система перевіряє валідність обраного адміністратором проєкту (можливі BlockProject_ProjectHasBeenRemoved_EXC, BlockProject_ProjectHasBeenBlocked_EXC).

7. Система здійснює операцію блокування й повідомляє менеджера цього проєкту та адміністратора про заблокований проєкт.

7. Система здійснює операцію блокування й повідомляє менеджера цього проєкту та адміністратора про заблокований проєкт.
РЕЗУЛЬТАТ Заблокування проєкту
ВИКЛЮЧНІ СИТУАЦІЇ

- BlockProject_ProjectHasBeenBlocked_EXC – проєкт вже заблоковано

- BlockProject_CancelButton_EXC – адміністратор натиснув кнопку "Відміна"

- BlockProject_ProjectHasBeenRemoved_EXC – проєкт видалено з системи

- BanUser_UserHasBeenRemoved_EXC – користувача видалено з системи

- BanUser_UserHasBeenBanned_EXC – користувача вже заблоковано
